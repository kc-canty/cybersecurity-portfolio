# Portfolio Foundations

This directory documents the standards used across all labs in this portfolio.

The goal of this portfolio is to demonstrate practical security, IAM, cloud, networking, and automation skills aligned to junior-to-mid level security roles, with a long-term focus on cloud security.

Labs are intentionally scoped to be:
- Beginner-friendly
- Time-boxed (60–75 minutes per session)
- Focused on concepts, not tool mastery
- Honest about skill level and progression

For role-specific lab recommendations, see the `/role-guides` directory.
