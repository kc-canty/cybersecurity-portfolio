# Cybersecurity Portfolio – Security, IAM, Cloud, and Networking

This repository documents my hands-on cybersecurity learning journey, focused on building practical skills aligned to **SOC Analyst, IAM Analyst, Network Security Analyst, and Cloud Security Analyst** roles, with a long-term goal of **Cloud Security Engineer**.

The portfolio is intentionally structured to show **progression**:
- Foundational security and operating system concepts
- Identity and access management across platforms
- Cloud and SaaS security fundamentals
- Networking and traffic analysis
- Exposure to enterprise-scale security challenges

This is a **living portfolio**. Labs are added incrementally as skills deepen.
